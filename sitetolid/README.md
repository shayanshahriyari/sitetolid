# Persian Cinematics

Build a premium, luxury, cinematic Persian website for a modern digital services company.

LANGUAGE & TYPOGRAPHY

The entire website must be in Persian (Farsi) with a fully RTL layout.

Use IranYekan, IranYekanX, or Vazirmatn (Vazir) as the primary font.

The typography must feel modern, elegant, premium, and highly readable.

PHASE 1 PAGES

Create the following pages:

Home

Services

Web Design

SEO

Website Page Design / UI Design

Digital Marketing

Banner Design

Logo Design

Every service must have its own dedicated detail page.

Pricing

One complete pricing page containing packages and pricing for all services.

About Us

Contact Us

Articles / Blog

Portfolio / Our Projects

BRAND COLORS

Use the following exact brand colors throughout the website:

🟢 Primary Green: #5EF37A

🟢 Light Green: #7FF9A0

🟣 Primary Purple: #AE7FDD

🟣 Dark Purple: #7544A7

🔵 Turquoise / Blue: #3ED0DA

Use these colors intelligently and with restraint.

Important: The colors must look luxurious, cinematic and sophisticated, NOT cheap or overly neon. Use dark backgrounds, gradients, transparency, shadows and subtle color accents to create a premium appearance.

DARK & LIGHT MODE

Implement a complete Dark Mode / Light Mode system.

Add a clear theme toggle.

Both themes must be professionally designed.

Preserve the brand colors in both modes.

The Light Mode must remain elegant and not become overly bright.

The Dark Mode should be cinematic and premium.

CINEMATIC EXPERIENCE — MANDATORY

Every page and every major section must contain at least one cinematic visual experience.

Each page should have its own cinematic treatment rather than repeating the same animation everywhere.

Examples:

Home → cinematic hero with layered visuals and smooth motion

Services → cinematic service showcase

Service Details → animated visual storytelling

Pricing → cinematic pricing reveal

About → cinematic company story / timeline

Portfolio → cinematic project showcase

Articles → cinematic editorial experience

Contact → cinematic final CTA

Use:

Smooth scrolling

Parallax

Scroll-based animations

Text reveals

Image reveals

Elegant transitions

Subtle 3D/depth effects

Premium hover interactions

Slow cinematic motion

Animations must feel smooth, sophisticated and intentional, never excessive or childish.

LUXURY VISUAL DESIGN

Use high-quality, elegant and cinematic imagery with:

Dramatic lighting

Premium compositions

Deep shadows

Subtle gradients

Atmospheric backgrounds

Glass/transparency used carefully

High-quality photography and visuals

Generous whitespace

Avoid generic templates, cheap stock photography, excessive rounded cards, cluttered layouts and random animations.

LOGO

Modernize and refresh the existing logo while preserving its core identity and recognizability.

The new version should feel:
Minimal + Premium + Modern + Cinematic

CONVERSION & ORDER FLOW

The entire website must be designed to turn visitors into customers.

Make ordering extremely easy and visible.

Use strong CTA buttons such as:

«ثبت سفارش»

«شروع پروژه»

«دریافت مشاوره»

«مشاهده تعرفه‌ها»

«درخواست همکاری»

Create a clear customer journey:

Discover → Explore Services → View Portfolio → Check Pricing → Contact / Place Order

The final result should feel like a high-end Persian digital agency website, with a strong cinematic identity, premium visual design, and a clear focus on converting visitors into customers.
